# Nome do aplicativo
Podcast Manager


### Descrição
Um app no estilo Netflix, aonda eu possa centralizar diferentes episódios de podcasts separado por categoria


### Domínio
Podcasts feitos em vídeo


### Features
- Listar os episódios em sessões de categorias
    - [saúde, fitness, mentalidade, humor]
- Filtrar eposódios por nome de podcast
